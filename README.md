# Movies Explorer — Frontend

Frontend application for the Movies Explorer project, built with React.

## Technology Stack

- JavaScript (ES6+)
- React
- CSS
- npm

## Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

### Production Build

```bash
npm run build
```
